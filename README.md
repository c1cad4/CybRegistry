# CybRegistry

Регистрации можно хранить в SQLite: `Registry(database_path, agent_factory)`.
Фабрика принимает `(id, capabilities)` и восстанавливает валидированный объект агента.
Реестр без аргументов остаётся сессионным и сохраняет прежний API.
Идентичности и возможности после регистрации не перезаписываются; повторный ID
отклоняется, в том числе при одновременной регистрации из разных процессов.

Каталог и проверка агентов

## Реализовано

Потокобезопасный реестр агентов процесса. Повторная регистрация идентичности не заменяет существующего агента. Реестр не является криптографическим удостоверением личности и при рестарте создаётся заново.
